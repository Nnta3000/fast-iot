# planting (Monge problems) — large-scale staging. GPU-only (hello/torch scan + cupdlpx master).
#
# Instances: EXACTLY OPTIMAL by construction (planted by complementary slackness), NO OT solver in
#   the ground truth, NO mass splitting. **Monge** problems (not Kantorovich): each source sends its
#   whole mass to ONE best target, so |S| = n_eff.
#
# FINDING (GPU / cupdlpx, measured on the laptop, n_eff<=500, 7 configs): with the target
#   first-order master, ONLY prune=none converges. tolerance and hysteresis BOTH cycle (0/7 converge,
#   hit the iteration cap). Reason: cupdlpx supports tie_break="none" ONLY (it has no lexicographic
#   re-solve), so the proof-covered tie-break that fixes HiGHS is unavailable; pruning then cycles.
#   => the jobs below use --prune-strategy none.
#
# Driver: iot_experiments/core/planting_sweep.py (builds the planted problem, then runs the loop with
#   the requested scan/master). Pin the GPU first (the queue does it via CUDA_VISIBLE_DEVICES).

# --- scale ladder, quadratic base (the base family), prune=none ---
python -m iot_experiments.core.planting_sweep --families quadratic --dims 8 --sizes 3200 6400 12800 --seeds 0 1 --g-profiles zero random --scan hello --solver cupdlpx --prune-strategy none --tie-break none --max-iterations 100 --out iot_experiments/core/out/planting/scale_quadratic
# --- scale ladder, diagonal (optional test) ---
python -m iot_experiments.core.planting_sweep --families diagonal --dims 8 --sizes 3200 6400 12800 --seeds 0 1 --g-profiles zero random --scan hello --solver cupdlpx --prune-strategy none --tie-break none --max-iterations 100 --out iot_experiments/core/out/planting/scale_diagonal
# --- scale ladder, lowrank ---
python -m iot_experiments.core.planting_sweep --families lowrank --dims 8 --sizes 3200 6400 --seeds 0 1 --g-profiles zero random --scan hello --solver cupdlpx --prune-strategy none --tie-break none --max-iterations 100 --out iot_experiments/core/out/planting/scale_lowrank
# --- dimension ladder at fixed n (quadratic base) ---
python -m iot_experiments.core.planting_sweep --families quadratic --dims 4 8 16 32 --sizes 3200 --seeds 0 --g-profiles zero random --scan hello --solver cupdlpx --prune-strategy none --tie-break none --max-iterations 100 --out iot_experiments/core/out/planting/dim_quadratic
# --- pruning control (cupdlpx): hysteresis on the SAME instances, expected to CYCLE ---
python -m iot_experiments.core.planting_sweep --families quadratic diagonal --dims 8 --sizes 3200 --seeds 0 --g-profiles zero --scan hello --solver cupdlpx --prune-strategy hysteresis --tie-break none --max-iterations 100 --out iot_experiments/core/out/planting/prune_control_cupdlpx

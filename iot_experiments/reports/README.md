## Regenerating

```bash
python iot_experiments/scaling/run.py    --family quadratic --marginal gmm \
  --sizes 200 400 800 1600 3200 --dims 2 4 8 16
python iot_experiments/marginals/run.py  --families diagonal quadratic lowrank \
  --marginals uniform gaussian gmm --n 800
python iot_experiments/families/run.py   --families diagonal quadratic lowrank \
  --marginal gmm --sizes 200 800 1600 --point-dimension 4
python iot_experiments/families/run.py   --families bilinear-psd --marginal gmm \
  --psd-ns 8 16 32 --point-dimension 2
```

The gradient/entropic arm and the frozen exact benchmark are regenerated by
`../benchmark/runner.py` (see `BENCHMARK_EXACT_REPORT.md`).

`legacy/reports/*` were produced by hand from the retired scripts in `../legacy/scratch/`; they
are not part of the current regen path.

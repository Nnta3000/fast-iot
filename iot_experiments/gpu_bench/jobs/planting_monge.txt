# planting (Monge problems) — large-scale staging. GPU-only (hello/torch scan + cupdlpx master).
#
# Instances: EXACTLY OPTIMAL by construction (planted by complementary slackness), NO OT solver in
#   the ground truth, NO mass splitting. These are **Monge** problems (not Kantorovich): each source
#   sends its whole mass to ONE best target, so |S| = n_eff.
#
# Finding from the local CPU sweep (n<=500): with the default pruning (tolerance, tie_break="none")
#   these instances often CYCLE; with pruning OFF they converge in 5-36 iterations. So the jobs below
#   use --prune-strategy none. The "default" column in the sweep output is kept for comparison only.
#
# Driver: iot_experiments/core/planting_sweep.py (it builds the planted problem then runs the loop
#   with the requested scan/master). Pin the GPU first (the queue does it via CUDA_VISIBLE_DEVICES).

# --- scale ladder, quadratic base (the base family), no pruning ---
python -m iot_experiments.core.planting_sweep --families quadratic --dims 8 --sizes 3200 6400 12800 --seeds 0 1 --g-profiles zero random --scan hello --solver cupdlpx --prune-strategy none --max-iterations 200 --out iot_experiments/core/out/planting/scale_quadratic
# --- scale ladder, diagonal (optional test) ---
python -m iot_experiments.core.planting_sweep --families diagonal --dims 8 --sizes 3200 6400 12800 --seeds 0 1 --g-profiles zero random --scan hello --solver cupdlpx --prune-strategy none --max-iterations 200 --out iot_experiments/core/out/planting/scale_diagonal
# --- scale ladder, lowrank ---
python -m iot_experiments.core.planting_sweep --families lowrank --dims 8 --sizes 3200 6400 --seeds 0 1 --g-profiles zero random --scan hello --solver cupdlpx --prune-strategy none --max-iterations 200 --out iot_experiments/core/out/planting/scale_lowrank
# --- dimension ladder at fixed n (quadratic base) ---
python -m iot_experiments.core.planting_sweep --families quadratic --dims 4 8 16 32 --sizes 3200 --seeds 0 --g-profiles zero random --scan hello --solver cupdlpx --prune-strategy none --max-iterations 200 --out iot_experiments/core/out/planting/dim_quadratic
# --- cycling study: same instance, default pruning on, to quantify the cycle ---
python -m iot_experiments.core.planting_sweep --families quadratic --dims 8 --sizes 3200 6400 --seeds 0 1 --g-profiles zero --scan hello --solver cupdlpx --prune-strategy hysteresis --max-iterations 300 --out iot_experiments/core/out/planting/cycling_quadratic

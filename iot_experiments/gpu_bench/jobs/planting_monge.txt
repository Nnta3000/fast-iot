# planting (Monge problems) — large-scale staging. GPU-only (hello/torch scan + cupdlpx master).
#
# Instances: EXACTLY OPTIMAL by construction (planted by complementary slackness), NO OT solver in
#   the ground truth, NO mass splitting. These are **Monge** problems (not Kantorovich): each source
#   sends its whole mass to ONE best target, so |S| = n_eff.
#
# Finding from the local CPU sweep (n_eff<=500): the DEFAULT tie_break="none" CYCLES on these
#   instances (300 iters, never converges) regardless of pruning; hysteresis alone does not save it.
#   With tie_break="lex_generic" (the proof-covered two-solve rule, spec section 4 item 2) it
#   converges EVERY time (48/48 configs, 5-18 iterations) and pruning can stay ON. So the jobs below
#   use --prune-strategy hysteresis --tie-break lex_generic --max-iterations 200.
#
# Driver: iot_experiments/core/planting_sweep.py (it builds the planted problem then runs the loop
#   with the requested scan/master). Pin the GPU first (the queue does it via CUDA_VISIBLE_DEVICES).

# --- scale ladder, quadratic base (the base family) ---
python -m iot_experiments.core.planting_sweep --families quadratic --dims 8 --sizes 3200 6400 12800 --seeds 0 1 --g-profiles zero random --scan hello --solver cupdlpx --prune-strategy hysteresis --tie-break lex_generic --max-iterations 200 --out iot_experiments/core/out/planting/scale_quadratic
# --- scale ladder, diagonal (optional test) ---
python -m iot_experiments.core.planting_sweep --families diagonal --dims 8 --sizes 3200 6400 12800 --seeds 0 1 --g-profiles zero random --scan hello --solver cupdlpx --prune-strategy hysteresis --tie-break lex_generic --max-iterations 200 --out iot_experiments/core/out/planting/scale_diagonal
# --- scale ladder, lowrank ---
python -m iot_experiments.core.planting_sweep --families lowrank --dims 8 --sizes 3200 6400 --seeds 0 1 --g-profiles zero random --scan hello --solver cupdlpx --prune-strategy hysteresis --tie-break lex_generic --max-iterations 200 --out iot_experiments/core/out/planting/scale_lowrank
# --- dimension ladder at fixed n (quadratic base) ---
python -m iot_experiments.core.planting_sweep --families quadratic --dims 4 8 16 32 --sizes 3200 --seeds 0 --g-profiles zero random --scan hello --solver cupdlpx --prune-strategy hysteresis --tie-break lex_generic --max-iterations 200 --out iot_experiments/core/out/planting/dim_quadratic
# --- cycling study (control): the SAME instances under the default tie_break="none" ---
python -m iot_experiments.core.planting_sweep --families quadratic diagonal --dims 8 --sizes 3200 --seeds 0 --g-profiles zero --scan hello --solver cupdlpx --prune-strategy hysteresis --tie-break none --max-iterations 300 --out iot_experiments/core/out/planting/cycling_control
